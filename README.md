# Story Generator Using Python

This project is a simple Python-based story generator. The user enters a topic or animal name, and the program generates a story based on the given input.

### Features

* Takes a topic or animal name as input.
* Includes predefined stories for animals such as horse, lion, and rabbit.
* Generates a basic story for other topics.
* Uses Python functions, dictionaries, strings, and user input.
* Beginner-friendly project for learning Python.

### How It Works

1. Run the Python program.
2. Enter a topic or animal name.
3. The program searches for a matching story.
4. If a matching story is not available, it generates a general story using the entered topic.
5. The story is displayed in the terminal.

The project uses a `create_story()` function and a dictionary to store predefined stories.

### Technologies Used

* Python
* VS Code

### Example

**Input:**

```text
horse
```

**Output:**

```text
Once upon a time, there was a beautiful horse named Thunder.
```

The project is useful for practicing Python basics and understanding how user input can be used to generate different outputs.
